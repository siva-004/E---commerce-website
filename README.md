# Nostra - E-Commerce Website

## Project Overview

Nostra is a responsive E-Commerce website developed using HTML, Tailwind CSS, and JavaScript. The website provides a modern shopping experience with product collections, search functionality, category-based filtering, and a contact page.

This project is designed to demonstrate front-end web development skills, responsive design principles, and JavaScript DOM manipulation.

---

### Home Page
- Responsive navigation bar
- Hero section with call-to-action button
- Brands section
- New Arrivals section

## Functionality

### Search Functionality

Users can search products by entering keywords in the search box. Products are filtered dynamically using JavaScript.

Example:

```text
Search: Shirt
Result: Men Shirt
```

### Filter Functionality

Users can filter products based on categories:

- Men
- Women
- Kids

Example:

```text
Men Selected
↓
Displays only Men products
```

### Combined Search and Filter

Users can use both search and category filters simultaneously.

Example:

```text
Search: Hoodie
Filter: Kids

Result:
Kids Hoodie
```
